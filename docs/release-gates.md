# Release-gate ledger

Status as of 1 October 2026, main `a4601925` (deployed, R1 candidate), hosted ledger 29. This is the one place that
says which release gates have evidence and which are still open.
`docs/release-checks.md` describes how to run the checks; this file records
where each gate stands.

- **PASS:** the linked evidence exists (PR, merge SHA, green exact-head CI run
  or a coordinator receipt). For engineering rows, PASS means merged with review
  and green CI. It does not mean owner, device or product acceptance.
- **DEVIATION:** the gate was changed or waived by a linked owner or
  coordinator decision.
- **BLOCKED:** open. The last column names the action that closes it.

Nothing is PASS without evidence. A gate with no public receipt stays BLOCKED
even if it is believed to be done.

Rows Q1–Q6 use the owner question numbers from the phase results; there are no Q3 or Q4 gates.

Links: `#N` is a pull request; `run N` is a GitHub Actions run of the CI
workflow at the merged head; `cN` is a comment on the named PR.

Reviewer model: from 1 October 2026, 09:34, the owner requires OpenAI GPT-6.1 Sol for all plan critiques and code
reviews. Earlier rows record the GPT-6 Astra reviews of their time.
